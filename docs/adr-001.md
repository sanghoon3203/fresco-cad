# ADR 001 — Qt 네이티브 캔버스 가설을 작은 실행으로 검증

작성: 2026-09-11 · 결정: **스파이크에 채택, 제품 스택 최종 승인 대기**. Gate 0A는 필수 정의와 로컬 실행 가능한 캔버스의 검증이다. 세 아키텍처·입력·출력·웹 격리·기업 배포를 포함한 Phase 0/1 전체 통과가 아니다.

## 결정과 이유

**Qt 6.8.3 공개 배포본 + C++20 + CMake + QML/Qt Quick + 커스텀 QSG 캔버스**를 사용한다. 설치한 macOS Qt 패키지는 universal이며 앱은 arm64 Release 빌드·실행을 통과했다. 실제 사용 CMake는 3.31.6, 프로젝트의 선언된 최저 CMake는 3.24다. 임시 SDK는 workspace의 `work/qt`에 두며 제품 소스로 복사하지 않는다. 실행 증거는 [검증 보고서](verification.md)에 고정한다. macOS 26.5 SDK의 AGL 제거로 첫 링크가 실패했다. 이미 설치된 macOS 15.4 SDK를 선택해 성공했으며 Qt 소스나 바이너리는 수정하지 않았다. upstream은 [AGL 링크 제거](https://github.com/qt/qtbase/commit/cdb33c3d562)를 반영했다. 제품용 Qt 패치 버전은 별도 승인 대상이다.

Qt Quick의 OS 창·입력·텍스트·접근성 기반과 C++의 공통 문서 모델로 작은 네이티브 실행을 만들 수 있어 사용자의 기본 가설을 유지한다. 웹 앱이나 다른 캔버스 프레임워크로 대체하지 않았다. 성능·패키징·라이선스 실험에서 가설이 탈락했을 때만 비교 스파이크와 후속 ADR로 바꾼다. **공개 6.8.3 스파이크는 추가 LTS 패치 수령·제품 배포 라이선스 승인을 뜻하지 않는다.** 최신 버전·플랫폼·상용 LTS 및 제3자 경계는 [라이선스·보안표](license-security.md)를 따른다.

## 최소 경계와 좌표 계약

| 경계 | 현재 소스의 책임 | 남은 범위 |
|---|---|---|
| `Document` | line/arc/text와 레이어 번호, validation, revision transaction, delta undo/redo, 내부 파일 저장 | 자동저장·감사 영속화·강제 종료 replay, 파일 어댑터 |
| `geometry.h` | mm 좌표↔논리 화면 px 변환, 거리·각도·호의 해석 기하 | 강건한 교차/접선·오프셋·트림 등 |
| `CadCanvas` | 포인터 입력, 선택·스냅, 고스트, batched QSG triangle 및 Qt text node, PDF 출력 | 공간 인덱스·증분 scene 갱신·고급 text/selection |
| QML | Qt Basic controls, 도구·속성·레이어·상태 표시, theme/catalog 소비 | 완전한 recipe 생성·상태별 접근성·IME 검증 |
| 외부 통합 | 현재 연결하지 않음 | [OpenMAIC·Archify·AI 경계](integrations.md)의 독립 스파이크 |

문서는 **mm, Cartesian Y-up, double**을 원천으로 쓴다. 선의 두 점, 호의 중심·반지름·시작각·sweep, 문자의 삽입점·내용·높이를 저장하며 화면 폴리곤을 도면으로 되저장하지 않는다. 화면 중심을 뺀 뒤 px로 변환하고 QSG 전달 단계에서만 float으로 줄인다. 호의 분할은 렌더링에만 적용하며 목표 sagitta 0.35 논리 px와 분할 상한이 있다. 큰 좌표와 극단 확대의 실제 보이는 오차는 후속 골든 시험 대상이다.

현재 trust boundary 상한은 100,000 entities, 파일 64 MiB, 좌표 절댓값 1e9 mm, text 4,096 UTF-16 code units, 고정 레이어 0/1/2다. 유한 수치·형식/버전·필수 및 미지 key·중복 JSON key·중복 ID·레이어 정수·도형 조건을 검사한다. 이는 지원 범위를 명시한 내부 형식이며 임의 CAD 입력을 읽는 범용 파서가 아니다. 실제 사용자용 허용오차 승인은 [호환성 매트릭스](compatibility-matrix.md)에서 별도로 관리한다.

## 변경·저장 계약

사용자 변경은 `Document::apply(additions, removals, expectedRevision)`에서 전부 검증한 뒤 한 번에 적용한다. 이동은 같은 ID를 한 transaction 안에서 교체한다. undo/redo는 엔티티 순서와 실제 double 값을 보존하는 delta를 사용한다. 이 경로를 이후 AI plan도 재사용하며 AI 전용 원본 수정 경로를 만들지 않는다. 현재 감사 로그·자동저장은 연결되지 않았다.

내부 `.fresco` 저장은 협력 프로세스용 lock → 디스크 hash 충돌 검사 → 임시 파일 작성/재읽기 및 엔티티 비교 → 이전 정상본 `.last-good` 저장 → `QSaveFile` 원자 교체 순서다. 다른 파일의 덮어쓰기와 외부 변경 감지는 실패로 반환한다. backup은 이전의 정상 저장본이며 미저장 변경 복구본이 아니다. 외부 비협력 writer의 마지막 hash 검사와 rename 사이 경쟁까지 없애지는 못한다. 전원 차단·강제 종료 주입 및 복구 UI는 미구현/미검증이다.

PDF는 `QPdfWriter/QPainter`로 **A3 가로, 1:100**의 벡터 출력 스파이크를 만든다. 용지·축척을 자동으로 바꾸지 않으며 영역 초과와 기존 파일 덮어쓰기는 거부한다. 가시 레이어만 출력하며 qreal QPainterPath 호를 사용해 1/16도 양자화를 제거했다. Qt의 cubic Bézier 근사는 남는다. 합성 샘플의 벡터·일본어 일부 검색·10000 mm 선의 출력 길이 100 mm는 검증했다. PDF 텍스트 추출의 일부 공백/문자 정규화 차이와 실물 인쇄·전체 폰트 보존은 미검증이다. JWW/JWC·DXF/DWG·SFC/P21·IFC는 미지원이다.

## 의도적으로 남긴 비용 상한

| 단순화 | 현재 비용/제한 | 교체를 판단할 증거 |
|---|---|---|
| scene 전체 재구성 | pan/zoom·preview에서 CPU geometry/text node 재작성 | 대표 혼합 장면 p95 frame interval >16.7 ms이면 안정 node·증분 갱신/공간 분할 검토 |
| O(n) 스냅/선택 | visible entity 순회; 끝점·호 중심/끝점, text 삽입점 중심의 최소 동작 | 포인터 처리 p95가 50 ms 목표를 넘으면 공간 인덱스 추가 |
| RAM delta history | 횟수 상한은 없지만 RAM 및 프로세스 수명에 의존 | 장시간 편집의 메모리·복구 요구에서 디스크 journal 도입 |
| 고정 3개 레이어·최소 문자 | 그룹별 축척/잠금 없음; text의 삽입점 선택, 세로쓰기·상세 글꼴 속성 없음 | 실제 첫 업무·파일 코퍼스의 불보존 항목으로 확장 |
| 고정 PDF 설정 | 일반 CAD print pipeline 전체가 아님 | 용지/축척/폰트별 화면↔PDF↔실물 골든 비교 |

새 범용 provider/plugin/service 추상화는 만들지 않는다. 한 구현의 작은 경계로 측정하고 실제 두 번째 요구가 생길 때만 확장한다.

## 검증과 결론을 분리

`core_check`는 정밀 좌표·문자 내부 왕복, transaction 거부 시 무변경, 순서/undo/redo, 저장 충돌·lock·악성/과대 입력을 검사한다. canvas 체크와 실제 GUI capture/benchmark는 별도 기록한다. 테스트 코드가 있는 것과 실행 성공은 다르므로 통과 횟수·시간·장비 수치는 실행 기록에서만 인용한다.

| 필수 증거 | 현재 판정 기준 |
|---|---|
| macOS arm64 build/run | 빌드 결과 + 실제 Mach-O architecture + 창 capture/상호작용 기록 |
| Windows x64/ARM64 | 실제 각 빌드·패키지·실기기 확인 전 미검증 |
| 성능 | 100k 혼합 장면의 구성비·표본·해상도·DPR·장비·Qt·전원 상태와 함께 기록 |
| pointer-to-preview | synthetic handler 시간 또는 `frameSwapped` 간격과 구분; 물리 입력부터 표시까지는 미측정 |
| 접근성·출력·통합 | [디자인 시스템](design-system.md) 및 [통합 판정표](integrations.md)의 미검증 항목 유지 |

Gate 0A 로컬 실행 스파이크는 통과했다. 100k 혼합 장면 frame interval p95 34.250 ms로 목표 16.7 ms에 미달했다. 다음 gate 0B는 scene 재사용과 필요한 경우 공간 인덱스로 이 병목을 줄이는 작은 성능 슬라이스다. Phase 0/1 전체 판정은 보류한다.
