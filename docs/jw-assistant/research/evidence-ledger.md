확인일: 2026-09-23 (JST). root의 추가 조사 기록이다. 분야별 원문과 목록은 [업무](japan-workflow.md), [Jw 기술/대안](jwcad-integration-market.md), [AI API](ai-provider-options.md)에 보관한다. 중복 URL을 다른 조사자가 열었다고 독립 사례 수에 더하지 않는다.

## 방법

일본어로 업무 흐름·수정·프리컷·신청 보정·Jw 강의·커뮤니티를 검색하고 관련 페이지 본문을 열었다. 출처를 공식 절차(A), 당사자 사례(B), 교육/강의(C), 커뮤니티 경험(D), 공급자 기술/상품 설명(E)로 구분했다. A도 기관·날짜·계약 범위를 벗어나 일반화하지 않는다. B/D는 해당 사례의 존재를 뒷받침할 뿐 업계 발생률을 증명하지 않는다. 기술 기능은 공식 문서/설치 도움말/제작자 설명으로 재확인한다.

동영상 전체 수강, 유료 강의 구매, 회원 게시판 접근, 인터뷰, 통계 표본조사, API 호출을 수행하지 않았다. 인터넷 문서는 시간이 지나면 바뀐다. 실제 출시 전에 endpoint·가격·서비스 제공 여부·법령/기관 안내를 재확인한다. 영구 원문 전체를 저장하거나 강의 내용을 재배포하지 않고 링크와 짧은 요약으로 기록한다.

## 조사로 변경한 요구사항

| 발견 / 추론 | 변경 요구사항 | 검증해야 할 다음 증거 |
|---|---|---|
| 내장 정리·비교·측정 및 외부변형 대안 존재 | 기존 대안을 기준선으로 비교, 독점 기능 주장 제거 | 최신 Jw 실기 및 고객의 실제 사용 방식 |
| 도면 검토의 왕복 사례 | Issue와 RevisionTask 분리, 원문-담당-수정본-검토 연결 | 대표/작도자 인수인계 관찰 |
| 선택 외부변형의 불완전 scope | CoverageReport와 not-observed 상태를 P0로 | 숨김·보호·블록·혼합 축척 fixture |
| 기관별 제출 절차 | 기관/프로젝트별 파일 프로필과 발행 manifest | 실제 고객이 사용하는 기관 안내의 최신판 |
| 일부 신청도서 점검 공공 대안 | 일반 누락 AI보다 회사 규칙·반영 확인 우선 | 기존 서비스 대비 효용과 WTP |
| 공급자별 보존·schema·과금 차이 | provider adapter, 명시적 전송, 평가·가격 버전 | 고객 계정의 현재 조건·실 API smoke test |
| 공개자료로 평균 공수 확인 불가 | 종전 임의 시간 범위를 요구사항에서 제거 | 파일럿의 전체 active time·대기시간·오탐 비용 |

## 유지할 불확실성

작업 횟수·월 비용·사무소 규모별 업무 비중·설계 사고 감소율은 아직 모른다. '시간 30% 절감', 'precision 95%' 등은 측정 목표다. 커뮤니티의 오래된 불편은 최신판에서 해소되었을 수 있다. 자료에 없는 공식 API의 부재를 절대적 부재로 단정하지 않되 제품 구현의 전제로 두지도 않는다. AI 여러 개를 함께 호출하면 품질이 자동 상승한다는 전제는 채택하지 않는다.
