# R1 조사·설계 스프린트 보고 — 일본 업무와 AI API 연결

보고일: 2026-09-24 (JST). 조사 기준: 2026-09-23~24. **판정: 조사·계획 개정 완료. 실제 Jw 연동, API 구현·성능 평가, 고객 파일럿은 미완료.** 파일명의 sprint-01은 보고 순번이며 로드맵의 구현 I1이 완료됐다는 뜻이 아니다.

## 이번 결정

첫 제품은 **Jw_cad를 유지하는 읽기 전용 도면 점검 + 검토 기록**으로 좁혔다. 첫 AI 확장 후보는 일본어 수정 지시를 출처가 있는 작업 목록으로 정리하는 기능이다. 설계자가 지시·대상·값을 확정하고, CAD 수정 또는 작업 완료는 별도 검증과 사람 확인을 따른다.

기존 Jw에는 정리·속성 변경·파일 비교·측정 기능이 있고 외부변형 대안도 있다. 이를 재구현했다는 사실만으로 유료 가치를 주장하지 않는다. 회사 규칙, 수정 반영 확인, 재검토와 예외 기록, 제출본 연결의 효용을 현장에서 검증한다. [기존 기능·연동 조사](research/jwcad-integration-market.md).

## 조사 범위와 발견

- 국토교통성·日事連·BCJ 자료에서 업무 단계와 지적/보정 절차를 확인했다. 기관별 절차는 전국 공통 규칙으로 처리하지 않았다.
- 일본 설계사무소의 프리컷·적입·현장 발행 사례, 강의 커리큘럼, 커뮤니티와 제작자 자료를 선별 열람했다. 사례의 존재와 업계 빈도를 구분했다. 모든 영상 수강·커뮤니티 전수조사는 하지 않았다.
- 설치된 공식 Jw 도움말과 외부변형 샘플을 읽기 전용으로 확인해 내장 기능 및 파일 교환 경계를 보강했다. Jw를 실행하거나 도면을 변경하지 않았다.
- OpenAI·Anthropic·Gemini의 공식 API/구조화 출력/보존/과금/제한 문서를 확인했다. 계정별 모델 접근·실사용 요금·응답 품질은 테스트하지 않았다.
- 정부 지원 AI 신청도서 사전점검의 공개 안내를 확인했다. 최초 제공 예정 기간과 현재 남아 있는 이용 링크를 구분했고, 실제 운영 가능 여부를 로그인 테스트하지 않았다.

자료와 한계: [업무 조사](research/japan-workflow.md), [추가 근거 원장](research/evidence-ledger.md), [공급자 조사](research/ai-provider-options.md).

## 분담과 검증

GPT-6 Sol agent 두 작업이 Jw 기술/기존 도구와 AI 공급자 조사를 분담했다. GPT-6 Luna는 일본 업무 조사와 온보딩 UX를 맡았다. 루트가 추가 공식·사무소 자료를 확인하고 요구사항·아키텍처·계획·평가 사례를 통합했다. Sol의 후속 검토에서 범위 동일성, 미저장 캔버스와 파일 hash의 차이를 반영했다.

- 합성 평가 JSON을 Node로 파싱하고 case ID 고유성, 필수 필드, locale, 기대/금지/판정 항목의 존재를 점검했다: **26개, 중복·누락 0**.
- 요구사항 ID를 집계했다: **JW 40개 / NF 16개**.
- 문서 상대 파일 링크·문서 형식을 점검했다. 세부 최종 결과는 아래 완료 기록을 따른다.
- 이번 변경은 연구 문서와 평가 명세다. 실행 엔진/UI를 수정하지 않았으므로 기존 18개 runtime 시험을 다시 실행하지 않았다. S0의 시험 결과는 [당시 보고](sprint-00-report.md)에만 귀속한다.
- 평가 runner·실제 모델 출력 채점·실도면 성능·ROI 측정은 하지 않았다. 26개 시나리오가 AI 성능 시험 26개 통과라는 뜻은 아니다.

## 아직 남은 것과 다음 스프린트

**다음 구현 I1의 목표는 실제 Jw 선택을 원본 변경 없이 가져와 좌표·축척·coverage가 맞는 검사 결과를 보여 주는 것**이다. Snapshot/Coverage 계약 → strict importer와 fixture → ja/en coverage UI → 실제 Jw 취소/실패/좌표 확인 순서다. [티켓 I1-01~06](roadmap.md#다음-구현-i1의-작업-티켓).

실제 사무소 자료가 없으면 protocol fixture·UI·계약은 계속 개발하되 고객 호환성 통과로 표시하지 않는다. 그다음 검토 이력/프로필·수동 업무 기록, FakeProvider, 허가된 계정/예산의 API 평가로 진행한다. 구조·법규 판단, 여러 JWW 자동 수정, 임의 자연어 작도는 장기 범위다.

이번 조사에서는 API 키를 요청하거나 유료 API를 호출하지 않았다. 설치·원본 도면·외부 계정·Git commit/push/PR도 변경하지 않았다. 계획과 코퍼스 명세는 작업 폴더에 저장되어 있다.
