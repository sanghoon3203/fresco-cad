# 도면 세트 생성기 (평면 → 입면 4면 · 단면상세 · 기초복도 · 기초상세) — 규칙 학습 · 단일 건물 모델 · 자기평가 루프

2026-10-02. 평면 생성기(`plan-generator.md`)와 같은 방식으로, 연습 도면(住宅A)의 레이어 분리·펜·문자종·치수 관습을 **측정**해서 규칙집으로 만들고, 하나의 평면 스펙 + 작은 `building` 블록에서 나머지 도면을 **유도**한다.

- 구현: `addons/jw-assistant/generator/`
  - `building.mjs` (단일 건물 모델: 레벨, 片流れ 지붕, 입면 파사드, 개구 높이, 기초 레이아웃, 단면 위치)
  - `sheet.mjs` (공용 작도 키트: Sheet, 도면 종류별 헤더 템플릿, A3 중립 도곽)
  - `draw-elevation.mjs`, `draw-section.mjs`, `draw-foundation.mjs` (기초복도 + 기초상세)
  - `evaluate-common.mjs`, `evaluate-elevation.mjs`, `evaluate-section.mjs`, `evaluate-foundation.mjs`
  - 헤더 템플릿 `header-template-{elevation,section,foundation,fdetail}.json` (연습 도면 헤더에서 펜/선종/문자종/SXF 표 수치만 추출, 메모·이름·뷰 위치 없음)
- 규칙집: `knowledge/office-drafting-rules-elevation.json`, `-section.json`, `-foundation.json`
- CLI: `node tools/generate-set.mjs spec.json outDir [--no-png] [--no-dll] [--only plan,elevation,section,foundation,detail]`
  → `plan/elevation/section/foundation/detail.jww` + `.png` + `.report.json` + `summary.json`
- 테스트: `tests/generator-set.test.mjs` (9개)
- 출력(추적 안 함): `outputs/generated-sets/<plan>/vN/`

연습 데이터는 `%TEMP%`에 ASCII 이름으로 복사해 읽기 전용으로 측정만 했다. 고객명·회사·주소·담당자·로고·표제란 내용은 어떤 파일에도 옮기지 않았다(테스트가 규칙집에 `様邸|株式会社|商会|建築士|登録第|丁目`가 없는지 검사).

## 1. 학습 방법
1. 코덱으로 디코드 → 레이어별 통계(종류/펜/선종/문자 크기, `%TEMP%\fw\analyze.mjs`).
2. 레이어마다 따로 PNG 렌더 → 몽타주(16칸)로 레이어 역할 파악.
3. 기준선(GL, 통り芯 Y1/X1)을 찾아 원점을 옮긴 뒤 수평/수직선 히스토그램(`hv.mjs`)과 엔티티 덤프로 오프셋을 mm 단위로 측정.
4. JWF 환경파일(Shift-JIS)에서 LAYSCALE, 펜 인쇄폭, 문자종 표 확인.
5. 생성 결과를 연습 도면과 **같은 bbox·축척**으로 나란히 렌더해 비교.

## 3. 단일 건물 모델 (`building` 블록)
평면 스펙 그대로 + 선택적 블록(기본값 = 住宅A 측정값):
```json
"building": {
  "levels": { "foundationTop": 400, "sill": 105, "floor": 40, "beamClear": 2720, "eaveBeam": 180, "ceiling": 2430 },
  "roof": { "type": "shed", "slope": 0.35, "low": "S", "eaves": { "low": 600, "high": 270, "gable": 450 } },
  "openings": { "head": 2000, "doorHead": 2000, "entranceHead": 2200, "byId": { "W1": { "head": 2060, "sill": -30 } } },
  "foundation": { "interior": "riser | grade-beam", "interiorLines": null, "manholeWidth": 600, "minCompartment": 2500000,
                  "anchor": { "size": "M12", "length": 400, "endOffset": 200, "maxSpacing": 2730 }, "postPitch": 910 },
  "section": { "axis": null, "at": null },
  "buildUps": { "roof": [...], "wall": [...], "interior": [...], "ceiling": [...], "floor": [...], "foundation": [...] }
}
```
- 레벨: GL→FL 545 = 400 + 105 + 40, 軒高 = 505 + 2,720 + 180 = 3,405, 천장 FL+2,430.
- 지붕: s = 낮은 쪽 외벽 중심선에서 경사 방향 거리, `top(s) = 軒高 + slope·s + 82/cosθ`, 최고 = top(깊이 + 높은 처마), 라벨은 5mm 올림.
- 입면: 각 방향에서 바깥을 향한 외벽(가까운 면이 먼 면을 가림, L형 지원). 경사 방향과 평행한 면 = 프로필(경사선), 낮은 쪽 = 지붕면 보임(면마다 처마 높이 다름), 높은 쪽 = 처마 띠.
- 개구 높이: 새시 높이 h는 표준 상단 2,000에서 매달림(sill = 2,000 − h), h ≥ 2,000이면 掃き出し.
- 기초: 외벽 = 立上り, 내벽 = 立上り(기본) 또는 地中梁. 2.5㎡ 미만 구획은 가장 짧은 경계 조각을 床組(大引)로 넘겨 합침. 人通口 = 구획 그래프의 신장 트리. 앵커·鋼製束 자동 배치. 모든 기초선 455 격자 강제(오류).
- 단면: 경사 방향으로 절단(455 반격자, 내벽과 겹치지 않는 중앙 부근). A3 1/50에 안 들어가면 자동으로 경사 직교 방향(경고).

## 4. 평가기 (결정적, JWW 재디코드)
점수 = 0.6·제도 + 0.4·계획(가중 통과율) − 오류 2점씩(최대 20). 공통: layer-role-purity, pen-per-layer(규칙집 `evaluation.pens`), text-style-sizes, fits-sheet(도곽 안 + **표제란 위**), dimension-sum-equals-overall(치수 문자 = 체인 실점 간격).
- **입면** (`evaluateElevations`): 도명 문자 + 위쪽 GL선으로 각 면 위치 복원 → views-present, level-lines-match-building(FL/軒/최고), level-chains-sum(545+2,860+3,050 = 최고, 400+105+2,720+180 = 軒高), **openings-match-plan**(평면 개구가 같은 u 위치·sill/head로 1:5 사각에 존재), roof-slope(경사·최고 높이·勾配 표시), **roof-drains-to-low-side**(경사선 낮은 끝이 계획상 낮은 쪽), siding-pitch, grid-bubbles, top-tiers-sum. 계획: window-heads-aligned, heads-below-lintel, height-limit(10m), eaves-overhang(低 ≥450, 高 ≥200, 케라바 ≥300), entrance-not-under-drip, **roof-spans-short-side**.
- **단면** (`evaluateSection`): 1:0 GL선 + 버블로 원점 → heights-match-building(기초천단·토대·FL·천장·슬래브 3층·푸팅), level-labels, heights-add-up, wall-assembly(외벽 7선), foundation-layers, roof-slope, insulation-drawn, build-up-callouts, rooms-labelled. 계획: ceiling-height ≥2,400, floor-height ≥450(令22条), foundation-minimums(立上り ≥120·GL 위 ≥300, 슬래브 ≥150, 근입 ≥240 — 告示1347), head-clearance.
- **기초복도** (`evaluateFoundationPlan`): 버블로 원점 → **risers-under-bearing-walls**(모든 외벽/내벽 아래 ±75 면선, 地中梁 모드는 ±300), perimeter-insulation, foundation-module, **anchors-at-column-ends**, **anchor-spacing ≤2,730**, anchors-on-risers, posts-on-grid, slab-labels. 계획: **manholes-not-under-walls**(문 아래가 아니면 경고), **void-compartments-reachable**(점검구에서 人通口로 모든 구획 도달), inspection-opening, post-spacing(短辺 >1,820 구획에 束), interior-walls-supported(床組로 넘긴 칸막이).
- **기초상세** (`evaluateFoundationDetails`): panels-present, section-dimensions-match(150/400/150/180/660/400/1,060/600), rebar-notes, foundation-minimums.

모든 출력: 코덱 재인코딩 **바이트 동일**, JwwHelper DLL(`readJww`) 재열기 **엔티티 수 일치** (CLI가 매번 검사, `summary.json`의 codec/dll).

## 6. 남은 한계
- 지붕은 片流れ만(切妻·寄棟·陸屋根 미구현). L형은 하나의 경사면으로 처리(골·谷 없음), 오목 모서리 처마 형상 단순화.
- 입면: 태양광, 배기탑, 玄関庇, 雨樋, FIX/すべり出し창 표현, 외부 계단·포치, 2층 미구현. 개구 높이는 표준 상단 + 스펙 높이로만 결정.
- 단면: 실제 소옥조(つなぎ梁·振れ止め)는 束 @1,820 + 母屋로 단순화. 절단 너머 가구·건구 입면, 床下AC 등 설비 없음. 통기층·防湿シート는 선이 아닌 콜아웃으로만.
- 기초: 앵커·人通口 위치는 **표준 규칙**(연습 A에는 기호가 없음) — 사무소 실측 확인 필요. 地中梁 단면은 FG2 하나의 일반형. 포치·玄関 단차 상세, 配筋 정량(정착 40d 등)은 문자만. 구조 계산(スパン表, 地中梁 断面 검정) 없음.
- 치수는 선+실점+문자(CDataSunpou 아님). 렌더러 기준 검토(Jw_cad 본체에서는 평면만 사용자 확인).
- 평가 만점 ≠ 완벽: 北側斜線·日影, 雨仕舞 상세, 단열 성능 계산은 미점검.
