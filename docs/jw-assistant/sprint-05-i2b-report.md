# Sprint 05 / I2B — 위치별 현장 메모와 백업 복원

날짜: 2026-09-26. 범위: 읽기 전용 시제품의 현장 정보 관리. 실제 CAD 변경·AI 통신은 이번에도 수행하지 않는다.

## 구현

- 같은 검사 문맥 안에 여러 위치의 메모를 저장한다. 저장 키는 도면/검사/분류 문맥과 카드 ID의 조합이며 전체 저장 상한은 100장이다.
- 기존 v1 기록은 엄격하게 검증한 뒤 메모리에서 v2로 변환한다. 명시적으로 저장하기 전에는 원래 저장 데이터를 바꾸지 않는다.
- 현장 메모 초안은 카드·도면 조건별로 보존한다. 그룹·언어·데모 화면을 전환해도 초안을 다른 도면에 붙이지 않는다. 화면 밖의 초안도 원래 조건에 묶어 일괄 저장할 수 있다.
- 미저장 현장 메모와 레이어 대응을 표시하고, 미저장 변경이 있으면 페이지 이탈 방지 핸들러를 등록한다. 브라우저 종료·충돌 복구용 자동저장은 아니다. 사무소 검토 판단/수치 규칙의 미저장 초안까지 이 저장소가 관리하는 것은 아니다.
- 현장 데이터 JSON을 붙여넣거나 로컬 파일로 선택해 검증한다. 메모·분류 개수를 확인한 다음 명시적으로 저장 데이터를 교체한다. 미저장 초안·변경된 미리보기·오래된 revision은 교체를 차단한다.
- 복원 전 정상 저장본을 백업으로 보존한다. 현재 JSON과 직전 백업을 화면에서 확인할 수 있다. 사무소 검토 판단 데이터의 JSON 복원은 별도 후속 범위다.
- 상세 분류는 넓은 화면에서 여러 열로, 마감 항목은 공간에 따라 열 수를 줄이도록 배치했다. 단일 선택 메뉴로 위치별 메모를 전환한다.

## 검증

`node --test addons/jw-assistant/tests/*.test.mjs`: **54/54 통과**.

추가 검사: v1 무기록 변환, 잘못된 legacy 거부, 카드 ID/문맥 분리, 100장 제한, 복원 내용 복사와 revision 처리, 손상/충돌/용량 오류, 초안 간 격리. 정적 서버 허용 목록에 새 모듈을 추가했다.

브라우저에서 합성 파일로 다음을 직접 확인했다.

1. 서로 다른 두 위치의 메모를 저장하고 v2 JSON에서 두 기록을 확인.
2. 두 번째 메모를 미저장 상태로 두고 그룹 0 → 1 → 0을 전환해 입력 보존 확인.
3. 원래 조건으로 일괄 저장, 일본어 → 영어 전환 후 값 보존 확인.
4. 두 메모를 한 메모 백업으로 교체하기 전 미리보기 확인. 이후 입력을 수정하면 적용 버튼이 비활성화됨.
5. 실제 복원 후 현재 기록 1장, 직전 백업 2장 확인. 잘못된 JSON은 오류로 거부.
6. 미저장 상태의 새로고침 시도 후 기존 입력과 문맥이 유지됨. IAB는 별도 JS 대화상자를 노출하지 않았으므로 모든 브라우저의 경고 문구·종료 UX를 검증했다고 주장하지 않는다.
7. 최종 미리보기 무효화 안내, 데스크톱 화면과 브라우저 오류/경고 로그 없음 확인.

실무 JWW, 좁은 화면 실측, Windows Narrator/IME, 다중 탭 동시 복원은 이번 수락 범위 밖이다. 기존 Node 검사와 이번 브라우저 검증을 실제 건축 설계 검증으로 대체하지 않는다.

## 분담과 남은 사항

GPT-6 Sol이 필드 저장 형식·이전 버전 변환·복원 계약 및 테스트를 구현했다. 루트가 UI·초안 보존·통합·브라우저 검증을 수행했다. Sol이 UI 저장/복원 경쟁과 문맥 연결을 추가 읽기 검토했다. SEED/Apple 참조는 기존 plain DOM/CSS 설계 원칙을 이어 사용했으며 공식 React 컴포넌트 인증은 아니다.

단일 탭 localStorage 시제품이라는 한계는 유지된다. 정상 저장소의 데이터 교체 복원은 가능하지만 손상된 primary를 덮어쓰는 복구는 차단한다. 이전 백업은 확인할 수 있고, 손상 원본을 보존하는 별도 복구 경로가 후속 과제다. 저장된 메모 삭제, 전체 변경 감사 이력, 도면 객체/방 자동 연결, Jw 쓰기와 API 연결은 미구현이다.

다음 게이트: 현장 카드와 확인된 객체/방 연결, 사무소 검토 기록 복원, 손상 저장소의 비파괴 복구, 파일 기반 작업 공간. 실제 CAD 쓰기는 기존 무손실·Undo 검증 게이트 후 진행한다.

GitHub 연결 안내를 받은 후 푸시를 다시 시도했으나 이 실행 환경의 로컬 Git은 사용자 이름/인증을 찾지 못했다. 대화형 푸시도 인증 응답을 기다렸다. 기능별 로컬 커밋은 보존하고, 최종 원격 완료 여부는 사용자 보고에서 구분한다. 참조 업무 도면은 포함하지 않는다.
