# Fresco CAD — 제품 정의 초안

기준일: 2026-09-10 · 상태: Phase 0, gate 0A 정의 문서. 제품 출시 또는 Phase 전체 통과 판정이 아니다.

## 1. 제품과 이번 게이트

일본 건축 실무용 사내 2D CAD를 신규 개발한다. 목표 플랫폼은 macOS Apple Silicon, Windows x64·ARM64이며, 목표 언어는 ja-JP 기본과 ko-KR·en-US이다. 최우선 가치는 좌표·치수·출력 정확성 및 원본 보존이다. 현재 언어·OS 지원 여부는 실제 빌드와 UI 검증 증거로만 판정한다.

이번 gate 0A의 산출물은 제품·호환성·법규 소스·라이선스/보안·기술 선택·토큰 초안과 가장 작은 실행 가능한 네이티브 캔버스 스파이크다. Phase 1 전체, Jw_cad 대체, AI 또는 기업 배포 완료를 의미하지 않는다. 실행한 범위·환경·명령·결과는 실행 보고에 별도로 남긴다. 구현되지 않은 UI 동작과 외부 형식은 미지원으로 표시한다.

파일 순서는 JWW/JWC → DXF/DWG → PDF → SFC/P21 → IFC로 고정한다. Phase 1 내부 문서와 벡터 PDF 기반 검증은 이 순서를 바꾸는 외부 형식 호환성 선언이 아니다. DWG는 회사가 승인한 합법적 SDK 확보 전까지 미지원이다.

## 2. 상위 업무 가설과 검증할 결과

아래 순위는 사용자 brief에서 추출한 제품 가설이다. 실제 사내 이용빈도 조사나 일본 건축 실무자 승인은 아직 없다.

| 순위 | 사용자 업무 | 성공 결과 | 후속 확인 |
|---|---|---|---|
| 1 | 기존 도면을 열어 치수·문자·축척·출력을 점검 | 원본을 보존하고 손실/대체/미지원 목록을 먼저 확인 | 익명화 코퍼스, 원 CAD 재개방, 인쇄 골든 |
| 2 | 평면·단면·상세의 선·호·문자를 정밀하게 수정 | 도면 mm 좌표와 화면 px가 분리되고 선택·스냅·이동을 undo | 수치 검사 + 숙련자 과제 관찰 |
| 3 | 레이어·그룹 축척·창호/부품을 재사용하고 출력 | 다른 축척에서도 문자/선종/용지 결과 보존 | 실제 템플릿·폰트·프린터 조건별 비교 |
| 4 | 익숙한 Jw 조작으로 반복 작업 | 좌/우 버튼·양 버튼 pan/zoom·클록 메뉴·단축키의 동작 계약 일치 | Jw 버전/설정 고정 후 숙련자 5명 시험 제안 |
| 5 | AI 제안과 교육으로 작업 보조 | 미리보기·승인·취소·한 transaction undo, 법규 출처 표시 | 코어 안정 후 독립 Phase 4 게이트 |

Jw_cad 공식 페이지는 Windows 10/11에서 동작하는 2D CAD로 소개하며, 2026-09-05 공개 버전을 10.03.6으로 안내한다. 이것은 비교 대상 정보이며 Fresco CAD의 해당 플랫폼 지원 증거가 아니다. [Jw_cad 공식 페이지](https://www.jwcad.net/), [공식 다운로드 안내](https://www.jwcad.net/download.htm) (확인: 2026-09-10).

## 3. 게이트와 제안 수치

수치는 개발 초기 제안이다. Jw 실무·출력 담당자의 승인 전에는 고객 수락 기준 또는 달성 성능으로 표현하지 않는다.

| 게이트 | 진입/통과 증거 | 현재 판정 |
|---|---|---|
| 0A — 정의와 최소 실행 | 필수 초안, 출처 확인일, 미지원 목록, 네이티브 캔버스 빌드·실행 및 한 runnable check 기록 | 이번 작업 범위; 최종 실행 보고에서 판정 |
| 0B — 스택 검증 | Qt 라이선스 경로, 세 아키텍처 실기기 결과, IME/폰트·격리 webview·인쇄 결과로 ADR 유지/변경 결정 | 미검증 |
| 1 — 내부 도면 수직 슬라이스 | line/arc/text, pan/zoom, grid/object snap, selection/move/layer, undo/redo, 원자 저장·복구, 벡터 PDF | 부분 스파이크와 전체 게이트를 구분; 전체 미검증 |
| 2 — JWW/JWC | read-only 골든 통과 후 별도 write gate; 버전별 재개방·속성·출력 보존, 손실 보고 | 미구현·실코퍼스 0건 |
| 3/4 — 확장 | 나머지 형식·건축 기능, AI/교육/기업 배포를 각각 별도 승인 | 미구현 |

성능 실험은 장면의 line/arc/text 구성비·엔티티 수·화면 해상도·DPR·GPU·OS·Qt·전원 모드·표본 수를 함께 남긴다. 제안 대표 장면은 선 70,000 + 호 20,000 + 문자 10,000개이며 준비운동 10초 후 60초 pan/zoom을 3회 측정한다. 목표는 p95 frame time ≤16.7ms, pointer-to-preview p95 ≤50ms다. CPU 명령 처리시간이나 offscreen 렌더 시간은 실기기 입력 지연·프레임 성능을 대신하지 못한다. 120Hz는 별도 장비에서만 검증한다.

저장 검증은 저장 전·임시 파일 작성 중·검증 후·교체 직전/직후의 강제 종료를 주입하고 20회씩 마지막 정상본·원본 checksum 보존을 확인하는 후속 게이트로 둔다. 단순 save/load 테스트는 강제 종료 복구 통과가 아니다. 전환 동작은 키보드 전용, 가시적 focus, reduced motion, 화면 읽기 도구와 일본어/한국어 IME 확정·취소를 실제 OS에서 검증한다.

## 4. 일본 법규 소스 레지스트리 초안

현재는 출처 목록이며 법규 엔진·검증된 법적 결론·최신 전체 조문 snapshot이 없다. 전국법, 시행령/규칙, 고시, 기술적 조언, 지자체 조례, 회사 자료를 별도 권위 수준으로 관리한다. 프로젝트 관할이 정해지지 않았으므로 도쿄는 소스 구조 검증 예시이며 전국 대체가 아니다.

|---|---|---|
| JP-EGOV-BSA | [e-Gov 建築基準法](https://laws.e-gov.go.jp/law/325AC0000000201) | 법령 ID 325AC0000000201. URL/검색 제목 확인; 이번 도구에서 본문 추출 0줄. 조문별 적용 버전 고정 미완료 |

위 URL 모두 확인일은 2026-09-10이다. 접속 확인일, 페이지 갱신일, 법령 공포일, 조항 시행일, 프로젝트 적용일을 서로 대체하지 않는다. 이번 조사에는 e-Gov 조문 본문 확보가 완료되지 않았으므로 법규 자동 판단을 활성화할 근거가 없다.

각 snapshot은 `source_id, authority, jurisdiction, law_id, article, title, canonical_url, published_at, effective_from/to, transitional_conditions, retrieved_at, content_hash, supersedes, original_language, translation_version, expert_review_status, reviewer, approved_at`을 갖도록 제안한다. 원문과 ja/ko/en 설명을 분리하고 전문가 승인 전 번역은 미검토로 표시한다. 조문·관할·시행일·프로젝트 조건 중 하나가 없으면 결론 대신 확인할 조건을 반환한다. 숫자 confidence는 근거 완전성 표시이며 적법성 확률로 제시하지 않는다.

법규 기능의 후속 시험은 전문가가 승인한 20개 합성 사례에 대해 적용일 전/당일/후, 경과조치, 서로 다른 관할, 출처 누락·갱신 실패를 포함한다. 모든 결론에 출처·조항·시행일을 제공하고 근거 누락 시 100% 보류하는 것을 제안 게이트로 둔다. 건축 확인 및 면허 전문가의 판단은 별도다.

## 5. 결정 경계

모든 수정은 공통 command transaction으로 검증·undo·감사에 연결한다. 외부 파일은 read-only 사전점검 후 후보 문서에 적용하며, 미지원 데이터를 조용히 제거하거나 원본을 덮어쓰지 않는다. 외부 실행파일·BAT·환경파일은 도면 열기만으로 실행하지 않는다. AI에는 읽기 전용 snapshot만 전달하고 승인된 schema의 command plan을 네이티브 미리보기 후 적용한다.

Jw_cad의 무상 사용 표기는 소스/부속물 자유 편입 허가로 해석하지 않는다. 공식 조건은 저작권을 유지하고 배포 형태·개변 및 유상 배포 시 샘플/화면에 조건을 둔다. 이번 산출물에 Jw 코드·바이너리·부품·샘플을 포함하지 않았다. [Jw_cad 저작권 및 사용 조건](https://jwcad.net/copyright.htm) (확인: 2026-09-10). 상세 라이선스·보안 위험과 기술 가설은 별도 문서에서 관리한다.

다음 결정은 실제 회사 도면의 승인된 익명화 목록과 Jw 비교 버전을 확보한 뒤 호환성 매트릭스의 첫 read-only 형식/버전 하나를 선택하는 것이다. 코퍼스 계획과 제안 허용오차는 `compatibility-matrix.md`에 있다.
