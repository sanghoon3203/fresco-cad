# Fresco CAD — Jw_cad 호환성 매트릭스 초안

기준일: 2026-09-10 · 상태: 제안/미승인. 실제 JWW/JWC 코퍼스 0건, Jw_cad 재개방 시험 0건. 모든 외부 형식의 가져오기·내보내기 호환성은 미구현·미검증이다. 내부 도면 스파이크 실행은 이 표의 통과 증거가 아니다.

## 1. 비교 기준과 출처

비교 앱 후보는 공식 안내의 Jw_cad 10.03.6(2026-09-05)과 별도 제공되는 8.25a(2022-04-10)다. 앱 버전은 파일 내부 버전 번호와 별도로 수집한다. 현재 다운로드·설치·실행하지 않았다. [공식 다운로드 안내](https://www.jwcad.net/download.htm) (확인: 2026-09-10).

공식 변경 기록에서 확인한 최소 근거는 다음과 같다. 웹 검색에서 반환된 공식 본문 발췌로 확인했으며 원 페이지 직접 조회에는 timeout이 발생했다. 공식 사이트의 사용자 게시판은 형식 규격 근거로 채택하지 않았다.

|---|---|---|
| 현재 조작 | 10.03.6은 양 버튼 이동 고속화와 M 버튼 드래그 설정 변경을 명시 | [현재 변경 기록](https://www.jwcad.net/versioninfo.htm) |

확인일은 모두 2026-09-10이다. 이 자료는 시험 대상을 정하기 위한 변경 이력이며 완전한 binary schema 또는 최신 parser 정확성 증거가 아니다. 정확한 포맷 원문·각 버전의 인코딩/수치 표현·부속 문법은 확보 및 라이선스 검토 전까지 미확인으로 둔다.

## 2. 형식과 워크플로의 경계

| 대상 | 다룰 역할 / 다른 파일과의 관계 | 첫 구현 게이트 | 현재 |
|---|---|---|---|
| JWW | 도면 파일. 객체·문자·레이어·축척·이미지/블록 등 실제 보존 항목을 버전별 조사 | 버전 식별·손실 사전점검 → read-only 화면/PDF 골든 → 별도 쓰기/reopen | 읽기·쓰기 미구현 |
| JWC | JWW와 별도인 레거시 도면 교환 대상. JWW 기능 집합을 동일하다고 가정하지 않음 | 수치 표현·문자/속성 한계 원문 확인 + 별도 코퍼스 | 읽기·쓰기 미구현 |
| JWS | 재사용 도형 파일; 전체 도면 열기와 부품 삽입을 분리 | 기준점·배율·레이어·문자·삽입 방향 보존 시험 | 미구현 |
| JWK | 기존 도형 파일; JWS 변환 시 축척·문자 위치·수치 정밀도 별도 점검 | 1:1 / 1:50 / 1:100 삽입 골든, 양방향 기능 손실 목록 | 미구현 |
| JWF | 환경 설정. 도면 객체와 설정 적용을 분리; 버전별 레이어명/인코딩 확인 | 알려진 설정만 미리보기·선택 적용, 실행 경로/알 수 없는 키 적용 금지 | 미구현 |
| DAT | 확장자가 한 규격을 뜻하지 않음. 이름/내용별 ZU_NAME, 창호/선기호, DXF 설정 등 분리 | 유형 식별 후 전용 데이터 어댑터; JW_OPT1/2/3 세부 문법은 원문 미확보 | 미구현 |
| 외부변형 | JWW_SMPL.BAT 등으로 설명되는 좌표·문자·속성 교환과 외부 프로그램 처리 흐름 | 승인된 프로토콜만 내부 command plan으로 변환; 임의 BAT 실행 없음 | 미구현·프로토콜 전체 미확인 |

DAT를 범용 도면 또는 실행 가능한 플러그인으로 처리하지 않는다. 부품·설정·외부변형이 같은 파일 열기 경로에서 임의 실행되지 않도록 경계를 유지한다. JWC_TEMP.TXT 기반 세부 왕복 문법과 BAT 지시자는 승인된 공식 부속 문서 확보 뒤 규격·인코딩·삭제 동작을 확인해야 하며, 이번 조사로 구현 확정하지 않는다.

## 3. 기능·조작·출력 검증표

모든 행은 미검증이다. 각 행에 형식, 파일 내부 버전, 작성/재개방 앱 빌드, OS, 글꼴, 설정, 시험 corpus_id, 보고서 checksum, 자동/사람 판정자를 연결한다. 기능 일부가 네이티브 코어에서 동작하더라도 Jw 상호운용성 판정을 올리지 않는다.

| 영역 | 보존/조작 항목 | 검증 방법 | 제안 수락 기준 |
|---|---|---|---|
| 기하 | line/arc/ellipse/polyline, 좌표·반지름·각도·단위·변환 | 기대 canonical 객체 대조, 편집 후 재개방 | 누락/추가 0; JWW 목표 좌표 오차 ≤0.001mm, 각도 ≤0.000001° |
| 속성 | 레이어·그룹·가시성/잠금·그룹 축척·선종/색/폭·블록/중첩 | 속성 집합 대조 + 숨긴 층을 포함한 재개방 | 식별자/값 100% 보존; 분해는 명시 승인된 범위만 |
| 문자/치수 | 일본어 전각/반각·세로쓰기, 한국어/영어, 줄바꿈·폰트·기준점·폭·연관 치수 | 문자열/속성 대조 + 화면/PDF/실물 출력 | 문자 소실·대체문자 0; 대체 폰트는 사전 경고; 종이 위치 오차 ≤0.1mm |
| 조작 | 좌/우 클릭, 양 버튼 확대/축소·이동, clock 방향/거리/타이밍, shortcut/취소 | 버전/설정 고정한 입력 시나리오 + 숙련자 비교 | 결정적 입력 시나리오 100% 일치; 숙련자 5명 핵심 과제 성공률 ≥90% 제안 |
| 출력/왕복 | 용지·축척·선폭·프린터 영역·vector/text·이미지·다른 축척 부품 | 열기 → 화면/PDF 골든 → 편집 → 다른 이름 저장 → 원 CAD 재개방 | 원본 checksum 불변, 비승인 손실 0, 용지 길이 오차 ≤0.1mm 및 전문가 육안 승인 |

JWC/JWK의 수치 한계는 원문 규격과 큰 좌표 코퍼스 측정 후 별도 수치로 합의한다. 낮은 정밀도에 맞춰 허용오차를 조용히 완화하지 않는다. 양자화로 위 목표를 넘으면 해당 영역 지원 실패 또는 명시적 손실 변환이다. 비교 전에 좌표 단위, 원점, 축 방향, 각도 방향, 호 끝점 포함 규칙을 고정한다.

골든 PDF는 600dpi, 고정 용지/축척/폰트/색 조건에서 비교한다. 제안 자동 지표는 종이 좌표로 정렬한 윤곽 편차 ≤0.1mm 및 도면 영역 내 차이 pixel 비율 ≤0.5%다. anti-aliasing·폰트 rasterizer 차이를 별도로 분류하고 이 지표만으로 통과하지 않는다. 엔티티·문자/치수 수치 검사와 실무자 승인도 필요하다. 검색 가능한 PDF는 텍스트 추출과 vector 존재를 별도 검사한다.

## 4. 익명화 코퍼스 계획

현재 수량은 0건이다. 다음 수량은 제안이며 확보 사실이 아니다. 회사 내부 파일을 자동 탐색·수집·업로드하지 않았다.

1. 소유자와 데이터 관리자의 사용 허가를 받은 30개 도면을 제안한다: 평면 10, 단면/입면 5, 상세 5, 배치/면적 5, 창호/문자/출력 집중 5. 전체가 대형 장면, 음수/큰 좌표, 복수 그룹 축척, 일본어 세로쓰기, nested block, 외부/내장 이미지, 치수, 선종을 포함하도록 한다. 합성 도면은 별도 `synthetic=true`로 구분한다.
2. 이름·주소·연락처·좌표상 위치·건물명·회사/고객명·도곽·메모·레이어/블록명·파일 경로·외부 참조·이미지·미리보기·숨긴 레이어를 검사한다. 문자열 길이/전각·반각/방향과 도면 구조는 유지하는 대체값을 쓰고 지리 좌표는 모든 관련 객체에 같은 평행이동을 적용한다. 결과를 둘이 검토하고 재개방하여 기능을 훼손하지 않았는지 확인한다.
3. 원본은 접근 통제 저장소에 보존하고 익명본만 개발 코퍼스로 승인한다. 원본 연결표와 hash는 별도 제한 저장소에 둔다. manifest는 corpus_id, provenance/permission, anonymization_version, 원 앱/내부 파일 버전, 엔티티 분포, 단위/축척, 폰트·설정, 예상 손실, 골든 checksum, 검토자를 기록한다. 배포/외부 AI 전송 허가는 별도다.
4. 8.25a 및 10.03.6 작성/재개방 조합과 회사가 실제 사용한 레거시 파일을 각각 최소 10개 제안한다. 애플리케이션 버전에서 내부 형식 버전을 추측하지 않는다. JWS/JWK 최소 10개씩, JWF 설정 5개, DAT 유형별 3개는 도면 코퍼스와 별도로 관리한다. 보유하지 않은 조합은 0건·미검증으로 남긴다.
5. 훈련/개발 20개와 잠금 holdout 10개를 분리한다. 변환 오차의 최대값·p95, 누락/대체 건수, 1회/10회 왕복 오차 증가량을 기록한다. 100%의 알려진 손실을 사전보고하고 승인 없는 덮어쓰기 0건을 게이트로 둔다. 손상/초대형/재귀 입력은 별도 합성 악성 코퍼스로 원본 불변·명시 실패를 검사한다.

## 5. 권리·판정·다음 작업

Jw_cad 프로그램·도움말·부속 데이터·제3자 GPL 구현은 이 문서의 사실 확인과 제품 자체 구현을 구분한다. 프로그램 무상 이용을 소스·부품·문서 재배포 또는 CAD 편입 허가로 간주하지 않는다. 포함할 코드/문서/폰트/SDK가 생기면 회사 법무·라이선스 담당자 승인 후 출처·버전·조건을 기록한다. [Jw_cad 공식 사용 조건](https://jwcad.net/copyright.htm) (확인: 2026-09-10). 이번에는 코드·바이너리·샘플·부품을 복사하지 않았다.

상태값은 `미구현`, `구현/미검증`, `자동검증 통과`, `사람 검토 대기`, `범위 승인`, `실패`로 제안한다. 테스트가 없으면 상태를 올리지 않으며, 범위 승인에는 형식/버전/기능/기기/코퍼스/허용오차/예외/승인일이 반드시 붙는다. 다음 작업은 승인된 합성 최소 도면 및 회사 코퍼스 목록으로 JWW 한 내부 버전의 read-only gate를 구체화하는 것이다.
