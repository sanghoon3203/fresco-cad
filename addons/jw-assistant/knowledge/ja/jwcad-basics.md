# Jw_cad 基礎(編集者向け)

> 한국어 요약: Jw_cad의 구조(레이어 그룹16×레이어16, 그룹별 축척, 선색/선종/문자종, 점·치수·블록·도형, 기준점, 실치수 vs 도면치수)를 AI가 편집할 때 알아야 할 관점으로 정리. 확인된 사실과 추측을 구분해 표기.

最終確認日: 2026-10-01 / 信頼度表記: **[確認]** = 複数の公開資料で一致、**[慣行]** = 一般的な運用例、**[要確認]** = 資料が薄い/版により異なる可能性。

## 1. 図面の骨格: レイヤグループ × レイヤ

- Jw_cad は **レイヤグループ 16 個(0〜F)× 各グループにレイヤ 16 個(0〜F)= 256 レイヤ**。[確認]
- グループ 3 のレイヤ 0 とグループ 4 のレイヤ 0 は完全に別物。図形の選択・編集はグループ単位/レイヤ単位で絞り込める。[確認]
- **縮尺はレイヤグループごと**に設定する(例: グループ 0 = 1/100 平面、グループ 1 = 1/20 詳細)。1 ファイルに複数縮尺が同居できるのが Jw_cad の特徴。[確認]
- 用紙サイズ(A0〜A4 など)は縮尺とは独立の設定。ステータスバーから別々に切り替える。[確認]
- レイヤの状態は 4 種(DARE ブログの凡例に基づく): **書込レイヤ(現在の作図先・赤表示)/編集可能(黒)/表示のみ(灰色・編集不可)/非表示(空白)**。書込レイヤは常に 1 つ(グループ+レイヤ)。「書込レイヤグループの切り替え忘れ」が最も多い事故原因。[確認]
- レイヤ名・レイヤグループ名は自由に付けられる。名前は図面ファイルに保存されるが、**名前に標準はない**(事務所ごと)。[確認]

### AI が編集時に守ること
1. 追加する図形は「どのグループ/レイヤに書くか」を明示する。既存図面のレイヤ名・使われ方を先に読み取り、それに合わせる(`layer-conventions.md` 参照)。
2. 縮尺が異なるグループの図形を同一座標系で比較・結合しない(実寸 mm に換算してから比較)。
3. 「全レイヤに対して一括変更」は避け、対象レイヤ/グループを限定する。

## 2. 線属性: 線色・線種・線幅

### 線色(1〜8)と補助線色
- 基本の線色は **線色 1〜8 の 8 色** + **補助線色** で計 9 色。[確認]
- **補助線色の図形は印刷されない**(下書き・位置決め用)。画面表示色とプリンタ出力色・線幅は別管理。[確認]
- 初期状態では線色 1 が緑系、線色 8 が赤系などに割り当てられる(色味は設定で変更可)。**色の意味(=印刷線幅)は図面ごと/事務所ごとに設定が違う**。[確認]
- 線幅は「基本設定 → 色・画面」タブで線色ごとに指定(出力色・線幅)。1/100mm 単位指定のオプションあり。**線幅は図形ではなく線色に紐づく**ため、「線を太くする」= 通常は線色を変える操作。[確認]
- 慣行: 細線(姿線・寸法線)< 中太(外形・建具)< 太線(断面・壁見切り)< 極太(図面枠)の順に線色 1→8 のどれかを割り当てる。具体的な色番号は事務所による。[慣行]

### 線種(1〜9)
資料(DARE ブログ、persc 解説)で一致した順序:

| 番号 | 名称 | 典型的な使い方 |
|---|---|---|
| 1 | 実線 | 外形線・見える線・壁・建具 |
| 2 | 点線1 | 隠れ線(詳細図・大縮尺) |
| 3 | 点線2 | 隠れ線(平面図 1/50〜1/100) |
| 4 | 点線3 | 隠れ線(配置図など小縮尺) |
| 5 | 一点鎖1 | 通り芯・中心線・基準線 |
| 6 | 一点鎖2 | 通り芯(ピッチ違い)・敷地中心線 |
| 7 | 二点鎖1 | 想像線・撤去予定・敷地境界 |
| 8 | 二点鎖2 | 同上 |
| 9 | 補助線種 | 補助線(印刷されない系統) |

- 別枠で「ランダム線 1〜5」(手書き風)がある。[確認]
- 上の番号⇔名称の対応は公開資料間で一致するが、**JWW バイナリ内の線種コードとの対応は実ファイルで検証が必要**。[要確認]
- 点線 2〜4 の使い分け(縮尺に応じてピッチを変える)は persc 解説に基づく慣行。[慣行]
- 通り芯の標準セットとして「線色 2 + 線種 5(一点鎖)」を紹介する資料あり。色番号は事務所差。[慣行]

## 3. 文字: 文字種 1〜10

- 文字は **文字種 1〜10** を「基本設定 → 文字」タブで定義(**幅・高さ・間隔・色 No.** を登録)。入力時は文字種番号か任意サイズを選ぶ。[確認]
- 文字サイズは基本的に **図寸(用紙上の mm)** で指定し、縮尺に連動して実寸が決まる。例: 縮尺 1/50 で高さ 3mm の文字 = 実寸 150mm 相当の大きさで配置される。[確認(基本動作)]
- 既定値: 環境設定ファイルの資料では幅/高さが 2.0, 2.5, 3.0, 4.0, 5.0, 6.0, 7.0, 8.0, 9.0, 10.0 mm 系列とされるが、**Windows 版 Jw_cad の既定値とは一致しない可能性**があり、図面ごとに変更されている。AI は既定値を仮定せず、対象ファイルの設定を読むこと。[要確認]
- 推奨運用(慣行): 室名 3〜3.5mm、寸法値 2.5〜3mm、注記 2.5〜3.5mm、図面名 5〜7mm、表題欄 5〜7mm(`drafting-rules.json` の text.* 参照)。[慣行]
- 文字サイズの変更は、文字種変更コマンド、または文字の属性変更で行う。縮尺を変えると「図寸で持つ文字」の実寸が変わる点に注意。

## 4. 点・寸法・図形・ブロック

### 点
- 「点」は交点・基準位置を示す図形要素。**仮点**は作図補助(通り芯上の目印など)として使われ、印刷しない運用が一般的(取り扱いは版・設定で異なるため **[要確認]**)。

### 寸法
- 寸法は「寸法線 + 寸法補助線 + 寸法値(文字)+ 端部(矢印/点)」で構成され、**寸法値は実寸(mm)から自動計算**される。[確認]
- 寸法設定で寸法値の文字種・小数桁・端部形状・補助線の長さ等を決める。「寸法図形」オプションを使うと寸法が 1 つの図形(まとまり)になる。[確認]
- 寸法線は書込レイヤに書かれる。**寸法専用レイヤを分ける**のが標準的運用。縮尺を変更した場合、寸法値は実寸なので変わらないが、文字・矢印の見かけは変わる。[慣行]

### ブロック(ブロック化)と図形
- **ブロック**: 複数要素を 1 単位に束ねたもの。移動・複写・削除を一括で行える。ブロック内の要素は専用の編集コマンドで個別編集する。[確認]
- **図形(.jws ファイル)**: 保存された部品(建具・家具・設備シンボル)。配置時にブロックとして図面に入り、**実寸/縮尺倍率を指定**して配置できる。[確認]
- 建具・家具・衛生器具・凡例はブロック/図形で入っていることが多い。AI が「サッシを大きくする」場合、ブロック内部の線を個別に動かさず、図形の差し替えまたはブロック全体の倍率変更・再配置で扱うかを判断する。
- JWW ファイルの `ブロック定義`(ブロックリスト)と `ブロック参照` は別物。参照を消してもブロック定義が残る場合がある。[要確認]

## 5. 基準点と座標

- 「基準点」には 2 つの意味がある: (a) **基準点設定**(作図中の相対座標の原点を指定するコマンド)、(b) **図形・ブロックの基準点**(配置時に掴む位置)。AI の指示文では区別して書く。[確認]
- 座標・長さは **実寸 mm** が基本(モデル空間は実寸)。レイヤグループの縮尺は「用紙上の見かけ」「文字・点・矢印の大きさ」「印刷」に効く。[確認]
- 実寸 vs 図寸:
  - 線の長さ・図形の位置 = 実寸(mm)
  - 文字サイズ・点サイズ・寸法矢印サイズ = 図寸(用紙 mm)が基本 → 実寸換算 = 図寸 × 縮尺分母
  - 例: 1/100 で文字高 3mm → 実寸 300mm。
- 角度は度数(反時計回り正)。軸角(水平軸の傾き)を設定すると、作図が傾く場合がある(`Snapshot` 取り込み時の注意)。[確認]

## 6. 印刷線幅の慣行

- 出力は線色ごとに線幅を割り当てる。JIS の線幅系列(0.13, 0.18, 0.25, 0.35, 0.5, 0.7, 1, 1.4, 2 mm、太さ比 1:2:4)に合わせる事務所が多い。[標準/慣行]
- 目安(慣行): 細 0.13〜0.18、中 0.25〜0.35、太 0.5〜0.7、極太(枠・断面) 1.0 以上。**実ファイルの設定を優先**。
- 補助線色は印刷されないので、AI が生成する下書き・ガイド線は補助線色に置くと安全。[確認]

## 7. AI 編集のための安全ルール(まとめ)

1. 既存図面の **レイヤ名・縮尺・線色/線種の使われ方を先に読む**。ルールが無ければ標準パターンに従い、ユーザーに確認する。
2. 実寸 mm で考える。「窓を広げて」は開口寸法(mm)・モジュール(455/910)・近隣建具との干渉を確認。
3. 変更は最小・局所的に。書込レイヤの切替、ブロック内部の編集、寸法値の手書き上書きは事故になりやすい。
4. ここにある数値の「既定値」は版・設定で変わる。必ず対象ファイルの値を優先する。
