最終確認日: 2026-10-01。**本ファイルの数値はすべて [慣行](設計実務で一般的な目安)。一次資料(法令・規格)ではない**。地域・グレード・工法で変わる。数値は 910 モジュール(芯々)基準で、内法は壁厚分(約 100〜130)を引く。

## 2. 配置の関係(隣接・動線)

- **水回り集約**: キッチン・浴室・洗面脱衣・トイレは給排水管の距離を短くするため隣接/上下階で重ねる。洗面脱衣室は浴室の隣。
- **玄関 → 廊下/ホール → LDK**: 玄関から LDK へ直行する動線。階段は玄関ホール付近か LDK 内(リビング階段)。
- **LDK は南面**(日射・採光)。北側に水回り・玄関・階段。
- **和室**: リビングに続き間で隣接する例が多い(襖で一体利用)。仏間・床の間を伴う場合は方位の慣習がある(地域差)。
- **寝室・子供部屋**は 2 階に集める例が多い。上階の水回りは下階の水回りの上に。
- **収納**は居室ごとに 1 箇所以上(クローゼット/押入)。階段下収納、玄関土間収納、パントリー。
- **トイレ**はリビングと寝室の両方から行きやすい位置。1 階に必須、2 階にも設ける例が多い。
- **勝手口・ごみ置き**はキッチンから外部へ。
- **窓**: 居室ごとに 1 面以上の外壁開口(採光 1/7・換気 1/20、法参照)。隣接建物の窓と向かい合わせにならないようにする。

## 3. 編集時の「関係チェック」(AI 用)

| 要求の例 | 確認する関係 |
|---|---|
| リビングの窓を広げる | 採光に有利だが、(1) 通り芯・柱・耐力壁への干渉(構造要確認)、(2) 隣接建具との間隔(最低 100〜200)、(3) 家具・カーテンボックス、(4) 防火設備(延焼のおそれ)、(5) 断熱・日射(南面は庇)、(6) 規格サッシ寸法(呼称ランク) |
| 部屋を広げる(壁を動かす) | 通り芯グリッド(455/910)、柱・耐力壁、建具位置、面積(広告帖数・採光比) |
| ドアを追加する | 有効開口 750〜800、開き勝手の干渉、廊下幅、壁芯からの位置、引戸なら引き代 |
| 収納を作る | 奥行 450〜900、扉の開閉、隣室の採光、納戸扱いの条件 |
| トイレ/浴室を移す | 配管の勾配(特に 2 階)、排水経路、換気 |
| 階段を移す | 蹴上げ/踏面/幅、踊場、上階の開口、頭上 2,100 以上の高さ確保 |
| LDK を大きくする | 梁・柱の位置、キッチンの動線、換気 |

## 4. 用途地域の概要(住宅設計に関係するもの)

- 住宅が建てられるのは主に **第一種低層住居専用地域〜準住居地域**(田園住居地域を含む)。工業専用地域は住宅不可。
- 低層住居専用地域: 絶対高さ 10m/12m、建ぺい率 30〜60%・容積率 50〜200%、北側斜線(5m+1.25)、第一種では店舗兼用住宅は非居住部分 50㎡以下かつ延べ面積の 1/2 未満。
- 中高層住居専用地域: 北側斜線(10m+1.25)、日影規制対象になりやすい。
- 近隣商業・商業: 建ぺい率・容積率が大きい(例: 建ぺい率 80%・容積率 200〜1,300%)、斜線は道路斜線 1.5。
- 防火地域・準防火地域との重ね掛けが多い(窓・外壁・屋根に制限)。
- **用途地域は図面ファイルからは分からない**。AI はユーザーに確認し、推測しない。数値はすべて `building-standards-law.md` の免責を適用。
