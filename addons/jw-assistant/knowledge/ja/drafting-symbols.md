# 日本の建築製図の慣行(JIS 製図・平面表示記号・図面種類)

> 한국어 요약: JIS Z 8310系 製図通則, JIS A 0150 建築製図通則(平面表示記号), JIS A 0151 建具表示記号에 근거한 선종류·선굵기·문자·축척·치수 기입·문 창 기호·도면 종류·실명 표기. 규격 본문은 유료/미열람이므로 공개 해설 기준 요약이며 신뢰도를 표기.

最終確認日: 2026-10-01。**JIS 規格本文(有料閲覧)は直接確認していない**。規格番号・概要は JSA/METI/自治体資料に基づく要約。数値は **[標準]**(JIS 等)/ **[慣行]** で区別。

## 1. 関連する規格

| 規格 | 内容 | 備考 |
|---|---|---|
| JIS Z 8310 | 製図総則 | 製図の基本事項 |
| JIS Z 8311 | 製図用紙のサイズ・図面の様式 | 用紙・輪郭・表題欄 |
| JIS Z 8312 | 製図 — 表示の一般原則 — 線の基本原則 | 線種・線幅 |
| JIS Z 8313 | 製図 — 文字 | 文字の高さ系列(2.5/3.5/5/7/10/14/20mm) |
| JIS Z 8314 | 製図 — 尺度 | 現尺・縮尺・倍尺 |
| JIS Z 8317 | 製図 — 寸法記入方法 | 寸法線・補助線・矢印 |
| JIS A 0150 | 建築製図通則 | 建築図面の線・文字・縮尺・**平面表示記号** |
| JIS A 0151 | 建具表示記号 | AD/SD/WD/AW 等の建具記号 |

- JIS Z 8310〜8317 は工業一般の製図規格。建築は JIS A 0150 が優先する(建築特有の平面表示記号・縮尺など)。
- JIS A 0150 は「建築製図通則」。**1/100・1/200 の平面図で使う平面表示記号**を定める(1/50 以大の詳細では実形に近く描く)。
- 慣用的な記号や作成者しか分からない記号は望ましくない、という考え方が示されている(平面表示記号の解説)。

## 2. 線の種類と意味

JIS の基本 4 系統: **実線・破線・点線・鎖線**(鎖線は一点鎖線/二点鎖線)。建築での使い分け:

| 線 | 意味(建築) | Jw_cad の対応 |
|---|---|---|
| 太い実線 | 断面の外形・切断された壁/柱の輪郭 | 線種 1 + 太い線色 |
| 中太〜細い実線 | 見える外形(見え掛かり)・建具・仕上げ線 | 線種 1 |
| 細い実線 | 寸法線・補助線・引出線・ハッチング | 線種 1 |
| 破線(点線) | 隠れ線(見えない部分)・上階/下階の見え隠れ | 線種 2〜4 |
| 一点鎖線 | 中心線・**通り芯(壁・柱の中心)**・基準線・隣地境界線 | 線種 5/6 |
| 二点鎖線 | 想像線・既存/撤去/将来の表示・敷地境界線の表現 | 線種 7/8 |

- 通り芯を実線の細線で代用してよい場合もある(紛らわしくない場合)。自治体の作成基準でも「基準線は鎖線、紛らわしくなければ細実線も可」とされる。
- 線の太さ: JIS の線幅系列は 0.13, 0.18, 0.25, 0.35, 0.5, 0.7, 1.0, 1.4, 2.0 mm の 9 種(比率 √2)。一つの図面では細:中:太 = **1:2:4** を基本とする。**0.2mm 以上**を推奨とする解説が多い。[標準]
- 設計図書では「太線=断面・外形、中線=見え掛かり、細線=寸法・補助」。

## 3. 文字

- 文字高さの標準系列: 2.5 / 3.5 / 5 / 7 / 10 / 14 / 20 mm(JIS Z 8313、ISO 3098 準拠)。[標準]
- 建築図面の解説: 漢字は 3mm 角以上、かな・数字は 2mm 角以上を目安とする(解説資料)。[標準/慣行]
- 常用漢字・楷書、外来語はカタカナ、あて字は使わない(自治体基準の例)。
- 慣行(縮尺 1/100 の平面図の場合): 図面名 5〜7mm、室名 3〜3.5mm、寸法値 2.5〜3mm、注記 2.5〜3.5mm。Jw_cad では文字種 1〜10 に登録して使う。[慣行]
- 文字の向き: **図面の下方または右方から読める**向きに書く(寸法値も同様)。

## 4. 縮尺

- JIS 尺度: 1/1, 1/2, 1/5, 1/10, 1/20, 1/30, 1/50, 1/100, 1/200, 1/300, 1/500, 1/600, 1/1000, 1/2000, 1/3000。[標準]
- 設計図書の目安(自治体基準の例):
  - 配置図 1/100, 1/200(広い敷地 1/300, 1/500)
  - 平面図・立面図・断面図 1/100, 1/200(住宅では **1/50** も多い)
  - 矩計図・階段詳細・各室詳細(展開図) 1/20, 1/50
  - 天井伏図 1/100, 1/200
  - 構造: 伏図・軸組図 1/100, 1/200
- 縮尺は表題欄に記入。**同一図面で縮尺が異なる図は図ごとに縮尺を記入**する。
- 住宅設計の慣行: 平面 1/50 or 1/100、立面・断面 1/50 or 1/100、矩計・詳細 1/20〜1/30。

## 5. 図面の種類(設計図書の順序の例)

意匠図(A): 表紙、特記仕様書、仕上表、求積図、**配置図、平面図、立面図、断面図、矩計図(詳細)**、階段詳細図、各室詳細(展開図)、**天井伏図**、建具表、その他。構造図(S): 伏図、軸組図、断面リスト、配筋図など。設備図: 電気(E)、給排水衛生(M)、空調(K)、昇降機(V)。

| 図面 | 内容 | 注意点 |
|---|---|---|
| 配置図 | 敷地・建物位置、方位、道路、隣地境界、外構 | 北を上。縮尺 1/100〜1/500 |
| 平面図 | 床上 1〜1.5m 付近で切断した水平投影。壁・建具・室名・寸法 | 北を上(やむを得ない場合も向きを一定に) |
| 立面図 | 東西南北の外観。軒高・最高高さ・GL・階高・開口位置 | 通常 4 面 |
| 断面図 | 建物を鉛直に切断。階高・天井高・床高・屋根勾配 | 切断線を平面図に表示(A―A) |
| 矩計図 | 外壁部の詳細断面。基礎〜屋根の各部寸法・仕上 | 1/20〜1/30 |
| 展開図 | 各室の壁面を展開。仕上・建具・設備位置 | 1/50 |
| 天井伏図 | 天井を見上げた図(照明・天井仕上) | 1/50〜1/100 |
| 求積図 | 面積算定(延べ・建築・敷地) | 小数点以下 2〜4 位表示が自治体で規定される例あり |

- 面積の単位は㎡、単位記号を付ける。寸法の単位は mm(単位記号を付けない)。大きな長さに m 表記を使う場合は単位を明記。
- 勾配は分子を 1 とした分数(1/8 等)。屋根勾配は「x/10」(例: 3/10)表記が一般的。

## 6. 寸法の記入

- 単位 mm、単位記号なし。寸法線に沿って図の下方/右方から読めるよう記入。
- 三段寸法(平面図外側): 外側から ① 全体(総寸法)② 通り芯間(スパン)③ 開口部・壁の位置(細部)。住宅では通り芯基準が主。
- 通り芯の番号: **平面図の左下隅を原点**として、桁行(横)方向に 1, 2, 3…、梁間(縦)方向に A, B, C…(自治体基準の例)。Jw_cad 住宅実務では X1, X2.../Y1, Y2... を使う事務所も多い。[慣行]
- 内法寸法(壁面間)を記入するか、壁芯寸法を記入するかは図面の目的で変わる(建築確認は壁芯、内装は内法が多い)。

## 7. 方位

- 平面図・配置図は原則 **北を上**。北が上でない図は方位記号(北矢印)を必ず記入。
- 方位記号は図面の見やすい位置に。立面図の名称は「南立面図」「東側立面図」など向く方角で付ける。

## 8. 建具記号(JIS A 0151)

材料記号 + 種類記号 + 番号:

| 記号 | 意味 |
|---|---|
| A | アルミニウム(Aluminum) |
| S | 鋼(Steel) |
| (ステンレス) | 表記は事務所・図面凡例で異なる(SS/SUS 等)。凡例を確認 [要確認] |
| W | 木(Wood) |
| P | プラスチック |
| D | ドア(扉) |
| W(後ろ) | 窓 |
| S(後ろ) | シャッター |

例: AD-1(アルミドア 1)、SD-2(スチールドア 2)、WD-3(木製ドア 3)、AW-4(アルミ窓 4)、AS-1(アルミシャッター 1)。詳細は建具表(寸法・開き勝手・ガラス・金物)を参照。[標準(概要)]

## 9. 平面表示記号(建具・開口の描き方・概要)

JIS A 0150 の図記号は 1/100〜1/200 の平面図用。描き方の概略(図記号そのものは規格図を参照):

| 建具 | 平面表現の要点 |
|---|---|
| 片開き戸 | 開き方向を **1/4 円弧**(扉の軌跡)+扉の線。ヒンジ側と開き勝手を示す |
| 両開き戸 | 左右 2 枚の扉と 2 つの 1/4 円弧 |
| 引違い戸(窓) | 壁の厚み内に **2 本のレールラインが前後にずれて重なる**(2 枚が見える状態) |
| 片引き戸 | 1 枚の扉線と開く方向の引き代 |
| 引込み戸 | 扉が壁内に引き込まれる(壁内に点線で引込み位置を示す) |
| 引分け戸 | 中央で左右に分かれて開く |
| 折れ戸 | 扉を折れ線(ジグザグ)で示す |
| 両開き窓・はめ殺し窓 | 壁を横切る線の本数・開き記号で区別(FIX は閉じた線のみ) |
| シャッター・網戸等 | 規格の専用記号または文字注記 |

- 壁開口部は **壁の線(2 本線)を切り、建具線を入れる**。建具位置は通り芯 or 壁面からの寸法で拘束するのが基本。
- 作図慣行: 開き戸の円弧は細線、扉は中太線。窓台・サッシ枠は細線。
