# レイヤ運用の典型パターン(Jw_cad・日本の建築実務)

> 한국어 요약: 공개된 여러 사례(Jw_cad 해설 사이트)에서 모은 레이어/그룹 할당 패턴과 변형. 사무소마다 규칙이 다르므로 AI는 "기존 도면의 규칙을 먼저 읽고 따르며", 없으면 아래 표준안을 제안만 한다.

最終確認日: 2026-10-01。**統一規格は存在しない**(JIS にも Jw_cad にもレイヤ名の標準は無い)。以下は公開例の「典型」と「ばらつき」。

## 1. 公開例の整理

### パターン A: 1 グループ内で要素別にレイヤを割る(意匠図中心)
persc の解説例(レイヤ番号はグループ内):

| レイヤ | 内容 |
|---|---|
| 0 | 通り芯・中心線 |
| 1 | 躯体(柱・壁) |
| 2 | 建具(サッシ・ドア) |
| 3 | 家具・設備 |
| 4 | 寸法 |
| 5 | 文字・注記 |
| 6 | ハッチング・塗り |
| 7 | 図面枠・タイトル |

### パターン B: グループ=専門分野、レイヤ=要素(設備系を含む実務)
persc(設備図解説)の例:

| グループ | 内容 |
|---|---|
| 0 | 意匠図(通り芯・壁・建具・寸法) |
| 1 | 電気設備(照明・コンセント・スイッチ・配線・分電盤・注記) |
| 2 | 給排水衛生設備 |
| 3 | 空調換気設備 |
| 4 | 防災設備 |
| F | 図面枠・表題欄 |

利点: グループ単位の表示/非表示で「意匠+電気」「意匠+給排水」の図面を切り出せる。

### パターン C: グループ=縮尺/図の種類
- 1/100 の平面グループと 1/20 の詳細グループを分け、**各グループに「線・寸法・文字」の同じレイヤ構成**を持たせる(縮尺が違う図は別グループにしないと文字サイズ・寸法が揃わない)。CAD 研究所・persc の説明。
- 縮尺を把握しやすいよう、**レイヤグループ名に縮尺を併記**する運用(例: 「平面 1:100」)が推奨されている。

### パターン D: グループ=建物/対象(初心者向け説明例)
- グループ 0: 住宅、グループ 1: 別の住宅、グループ 2: 周辺状況(道路・河川・線路)。グループ内レイヤ: 0=壁、1=屋根、2=ドア(おとちゃんぶろぐ)。
- 教育用の簡易例。実務でそのまま使われることは少ない。

## 2. 典型パターンの抽出(AI のデフォルト推定に使う)

共通して現れる要素の順序(多くの例で 0 に近いほど「基準」、大きいほど「注記・枠」):

1. **通り芯・基準線**(一点鎖線)— ほぼ全例でレイヤ 0 か最初のレイヤ。
2. **躯体・壁**(柱・壁・基礎)
3. **建具**(サッシ・ドア)
4. **家具・設備・衛生器具**
5. **寸法**(通り芯寸法/内法寸法を分ける事務所もある)
6. **文字・室名・注記**
7. **ハッチング・仕上げ・塗り**
8. **図面枠・表題欄**(最後のレイヤ/最後のグループ F に置く例が多い)

ばらつき:
- 寸法と文字を同一レイヤにする事務所もある(2 つ分けは慣行であって義務ではない)。
- 通り芯を最下層(0)に置くか、補助線色の別レイヤに置くか。
- 図面枠をグループ F とする例と、各グループの最後のレイヤとする例。
- 柱・壁を同一レイヤにする/分ける。
- 設備を意匠と同一グループに入れるか、別グループにするか。

## 3. AI の判定手順(提案)

1. 対象 JWW の **レイヤグループ名/レイヤ名**を取得。名前が空なら次へ。
2. 各レイヤの **図形統計**(線種=一点鎖線が多い→通り芯、文字が多い→注記、平行線ペアが多い→壁)から役割を推定(確信度を付け、断定しない)。
3. 推定が弱い場合は、ユーザーに「このレイヤは壁ですか?」と確認する。
4. 新規作図は、既存ルールに合わせる。ルールが読めなければ **パターン A** を既定にし、変更前に提案として提示する。
5. 補助(下書き)図形は **補助線色/補助線種**に置く(印刷されない)。

## 4. 線色・線種の典型対応(要素別)

(あくまで慣行。色番号は事務所ごとに異なるため、**意味(太さ・用途)で捉える**。数値詳細は `drafting-rules.json` の `linestyle.*`)

| 要素 | 線の太さ感 | 線種 |
|---|---|---|
| 通り芯・中心線 | 細 | 一点鎖線(線種 5) |
| 壁(断面)・柱 | 太〜中太 | 実線 |
| 建具・サッシ | 中〜細 | 実線 |
| 家具・設備 | 細 | 実線 |
| 隠れ線 | 細 | 点線(線種 2〜4) |
| 想像線・撤去・敷地境界 | 細 | 二点鎖線(線種 7/8) |
| 寸法線・補助線 | 細 | 実線 |
| 図面枠 | 極太 | 実線 |

## 5. 官庁・事務所標準との関係

- 公共建築では「CAD 図面作成要領(国土交通省 官庁営繕)」等でレイヤ名を定めるが、**これは SXF/DWG の名称規則**であり、Jw_cad のレイヤ番号とは別体系。JWW との変換時にレイヤグループ/レイヤ番号へマッピングされる(iJCAD 等の書出しで振り分け設定)。本資料では詳細未収録 → Gaps。
- 設計図書の記号(図面種別): 建築(意匠)A、構造 S、電気 E、機械(給排水衛生)M、空調 K、昇降機 V、他 X(自治体の設計図書作成基準の例)。図面番号接頭辞の慣行として有用。

## Gaps

- 実際の設計事務所(特に住宅設計)の内部ルール(レイヤ名一覧)は非公開が多く、**一次資料で確認できたのは教育/解説サイトの例のみ**。出現頻度の統計はない。
- 官庁営繕 CAD 基準のレイヤ名(SXF 名称)は未取得。
- 書籍(Jw_cad 入門書・建築製図書)の内容は著作権の観点から要約も行っていない。
