# モジュールと寸法(尺モジュール・畳・壁厚・建具・サッシ・階段)

> 한국어 요약: 910/455 척 모듈, 미터모듈 1000, 다다미 4종(교마·주쿄마·에도마·단치마), 1帖=1.62㎡ 광고 기준, 벽 두께, 문·창 치수, 샷시 호칭(16509 등) 읽는 법, 계단 치수. 법 수치와 관행 수치를 구분.

最終確認日: 2026-10-01。区分: **[法]** 法令 / **[標準]** 業界規格 / **[慣行]** 実務慣行。

## 1. モジュール

| モジュール | 基準寸法 | 内容 |
|---|---|---|
| 尺モジュール(尺貫法) | **910mm(3 尺)**、半間 **455mm**、1 間 = 6 尺 = 1,820mm(実務では 1,818mm の場合もある) | 木造在来の標準。柱芯々を 910 の倍数で計画 |
| メーターモジュール | **1,000mm**(半分 500mm) | ゆとり・バリアフリー重視、ハウスメーカー・マンションで採用 |
| 1/4 モジュール | 227.5mm | 内装・家具の細かな割付(尺モジュールの 1/4) |

- 1 尺 = 約 303.03mm(10/33m)。3 尺 = 909.09mm ≒ 910。[慣行]
- 木造軸組は **柱芯(通り芯)を 910 グリッドに乗せる**のが基本。壁の中心 = 通り芯。壁面の位置は通り芯±壁厚/2。
- 910 モジュールの廊下有効幅: 柱芯 910 − 柱・壁厚(約 105〜130)≒ 780〜800mm 前後。メーターモジュールは 1,000 − 壁厚 ≒ 870〜890mm。[慣行]
- 1 坪 = 1 間 × 1 間 = 約 3.3058㎡(400/121㎡)。1 間 = 1,818mm(約)。実務の計画寸法では 1,820mm を使う。

### 用語
- **芯々**(しんしん): 柱・壁の中心から中心。
- **内法**(うちのり): 壁・建具の内面間の有効寸法。
- **壁芯面積**: 壁の中心線で囲んだ面積(広告・確認申請の延べ床面積の基準)。**内法面積**: 壁の内側で囲んだ面積(登記の区分所有の床面積など)。

## 2. 畳と帖(㎡換算)

| 名称 | 寸法(幅×長さ) | 1 枚の面積 | 主な地域 | 6 帖の面積(畳のみ) |
|---|---|---|---|---|
| 京間(本間・関西間) | 955 × 1,910 | 約 1.824㎡ | 関西・中国・四国 | 約 10.9㎡ |
| 中京間(三六間) | 910 × 1,820 | 約 1.656㎡ | 中部・東北・北陸の一部 | 約 9.9㎡ |
| 江戸間(関東間・五八間・田舎間) | 880 × 1,760 | 約 1.549㎡ | 関東・東北・新築全国 | 約 9.3㎡ |
| 団地間(公団サイズ) | 850 × 1,700 | 約 1.445㎡ | 公団・マンション | 約 8.7㎡ |

- **不動産広告の帖数基準**(不動産の表示に関する公正競争規約施行規則): **1 帖 = 1.62㎡ 以上**(各室の壁芯面積 ÷ 帖数)。実際の畳寸法ではなく広告上の最低基準。[標準(業界自主規制)]
  - 換算: 4.5 帖 ≥ 7.29㎡ / 6 帖 ≥ 9.72㎡ / 8 帖 ≥ 12.96㎡ / 10 帖 ≥ 16.2㎡ / 12 帖 ≥ 19.44㎡ / 16 帖 ≥ 25.92㎡。
  - 逆算: 面積 ÷ 1.62 = 広告上の最大帖数(切り捨て)。
- 図面上の和室「6 帖」は、**畳の種類(地域・工法)によって実際の大きさが違う**。畳割り(京間)か柱割り(江戸間)かで、室内寸法が変わる点に注意。
- 柱割り(江戸間): 柱芯 910 グリッドで、畳 880×1760 がほぼ内法に納まる。畳割り(京間): 畳の大きさを基準に柱の位置を決める(柱芯が 910 の倍数にならない)。[慣行]
- 和室の一般的な広さ: 4.5 帖 約 2,730×2,730(芯々) / 6 帖 約 2,730×3,640 / 8 帖 約 3,640×3,640。(910 グリッド、芯々)[慣行]

## 3. 壁厚(平面図での表現)

**公的な一律基準はなく**、構造・仕上・縮尺で変わる。平面図は壁芯(通り芯)を基準に、壁の両側へ半分ずつ振り分けるのが標準的。

| 構造/部位 | 典型的な壁の厚み(仕上込み) | 備考 |
|---|---|---|
| 木造軸組・内壁(大壁) | 約 **120〜135mm**(柱 105 + 両面 石膏ボード 12.5 + 下地) | 柱 105 角 / 120 角 |
| 木造軸組・内壁(真壁) | 約 105〜120mm | 柱が見える。和室 |
| 木造軸組・外壁 | 約 **150〜230mm** | 柱 105/120 + 外装(通気層+サイディング)+ 断熱。付加断熱で更に厚い |
| 木造 2×4(枠組壁工法) | 外壁 約 140〜200mm、内壁 約 110〜130mm | 2×4 の材 38×89 / 2×6 38×140 |
| RC 外壁 | 約 **150〜250mm**(+ 仕上・断熱で 200〜330mm) | 構造設計による |
| RC 内壁(耐力壁) | 150〜200mm | 構造設計による |
| 軽量鉄骨(LGS)間仕切 | 約 **75〜125mm** | スタッド 45/65/90 + 両面ボード |
| S 造外壁(ALC) | 約 100〜150mm | ALC 100〜150 |
| 間仕切り(コンクリートブロック) | 100〜150mm | |

- 柱サイズ: 3.5 寸角 = 105mm、4 寸角 = 120mm(木造住宅で一般的)。柱の最小は構造規定(令43条)による。[慣行]
- 壁厚は **確認申請の壁芯面積・開口寸法・内法寸法**に影響する。AI が壁を動かす場合は「通り芯は変えず壁線をオフセットする」か「通り芯ごと移動」かを区別。
- 図面上の壁表現: 壁の両面の線(外形線・中太線)を平行線で描き、その間(壁厚)を空白またはハッチングで表す。1/100 では壁厚を省略して 1 本の線表現もある(1/200 以下)。

## 4. 建具寸法(住宅)

寸法は **建具幅(枠外/見付)** と **有効開口幅(内法)** を区別する。

| 部位 | 典型的な建具幅 | 有効開口の目安 | 備考 |
|---|---|---|---|
| 室内ドア(片開き) | 780〜910 | 有効 **700〜800** | 910 モジュールで 780 建具が主流。車いす対応 有効 800 以上 |
| トイレドア | 建具 700〜780 | 有効 **600〜750** | 狭めの住宅で 600 台 |
| 玄関ドア(片開き) | 建具 **900〜1,000** | 有効 **800〜900** | 親子ドアは 1,200 前後 |
| 玄関引戸 | 建具 1,500〜1,800(2 枚) | 有効 1,300〜1,600 | |
| 和室襖(引違い) | 1,820(間口 1 間 2 枚) / 910(半間) | | 押入は 1 間 2 枚、半間 1 枚 |
| 浴室ドア(UB) | 有効 600〜800 | | UB 仕様による |
| 掃き出し窓 | 幅 1,690 × 高 2,030(呼称 16520)等 | | 次節参照 |
| 腰窓 | 幅 1,690 × 高 970(16509)等 | | 次節参照 |

- **有効開口 750〜800mm** は一般的な設計目標(ユーザ指針)。ただし一律の法的基準ではない(バリアフリー法の誘導基準・住宅性能表示の高齢者配慮でそれぞれ有効幅の基準あり)。[慣行]
- 開き戸は **開き勝手(ヒンジ側)と円弧(開く範囲)が家具・隣接ドアと干渉しない**ことを確認。引戸は引き込み/引き残し寸法が必要。

## 5. サッシ(既製アルミ・樹脂サッシ)の寸法呼称

### 呼称の読み方(日本の一般的な住宅用既製サッシ)
**5 桁の呼称 = 幅 3 桁 + 高さ 2 桁**(メーカー・シリーズによって細部が違う)。

- 前 3 桁: **幅の呼称寸法(内法基準寸法を 10mm 単位)**。例: 165 → 1,650mm。
- 後 2 桁: **高さの呼称寸法(100mm 単位)**。例: 09 → 900mm、20 → 2,000mm。
- 呼称は枠の **内法基準寸法**で、枠の外形寸法・取付開口寸法とは異なる。

| 呼称 | 幅×高さの呼称 | 枠外形(製品寸法)の例 | 用途 |
|---|---|---|---|
| 16509 | 1,650 × 900 | **約 1,690 × 970**(幅 +40 / 高さ +70) | 腰窓(引違い・リビング/和室) |
| 16520 | 1,650 × 2,000 | **約 1,690 × 2,030**(幅 +40 / 高さ +30) | 掃き出し窓 |
| 16011 | 1,600 × 1,100 | 約 1,640 × 1,170 | 腰窓 |
| 06009 | 600 × 900 | 約 640 × 970 | 小窓 |

(幅 3 桁が 11x〜12x の小幅サッシは資料間で端数に差があり本資料では未収録。**メーカー寸法表を優先**。上は代表例。幅 +40 / 高さ +70(腰窓)・+30(掃き出し)は一部資料の目安で、シリーズ差あり [要確認])

### 取付開口(下地開口)の目安
- 呼称に **幅 +50mm、高さ +75mm**(掃き出しは高さ +45mm)を足した寸法を躯体/下地の開口とする、という現場の目安がある(幅は両側 20+20+クリアランス 10、高さ下 40+上 30+5)。 [慣行]
- 例: 16509 → 開口 W1,700 × H975、16520 → W1,700 × H2,045。

### AI 編集時の注意
- 「窓を広げて」の指示は、**呼称のランクアップ**(例: 16509 → 17409 or 18009)か、**開口を壁の通り芯・隣接建具に対して数値で広げる**かを区別。
- 既製サッシの規格寸法(幅 6〜18+、高 03・05・07・09・11・13・15・18・20・22 等)に合わせると、後で発注可能。規格外は特注(コスト増)。[慣行]
- 窓台高さ: 腰窓の下端は **FL+約 900(900〜1,100)**。掃き出しの下端は FL+約 50 以内(テラス/ウッドデッキ高と連動)。[慣行]
- 規格寸法の一次資料(日本サッシ協会「標準規格寸法」)は本文を取得できていない → Gaps。

## 6. 階段・段差の寸法

法令([法] 令 23 条・24 条・25 条):

| 階段の種類 | 幅 | 蹴上げ | 踏面 |
|---|---|---|---|
| **住宅**(共同住宅の共用階段を除く) | **75cm 以上** | **23cm 以下** | **15cm 以上** |
| 共同住宅の共用階段・一般建築物(下記以外) | 75cm 以上 | 22cm 以下 | 21cm 以上 |
| 直上階の居室面積が 200㎡超の地上階 等 | 120cm 以上 | 20cm 以下 | 24cm 以上 |
| 中学校・高校・劇場・映画館・集会場等 | 140cm 以上 | 18cm 以下 | 26cm 以上 |
| 小学校(児童用) | 140cm 以上 | 16cm 以下 | 26cm 以上 |

- 踊場: 高さ **4m 以内ごと**に踏幅 1.2m 以上の踊場(住宅の直階段等。学校等は 3m 以内ごと)。[法]
- 回り階段の踏面は、**狭い方の端から 30cm の位置で測る**。[法]
- 手すりは階段に設置(令 25 条)。両側設置+滑り止めで寄宿舎等の寸法基準が緩和される告示あり(蹴上げ 23 以下・踏面 19 以上)。
- **住宅の設計慣行**(法定の最低に対し緩やか): 蹴上げ 190〜200mm、踏面 220〜250mm、幅 780〜910mm、蹴上げ×2 + 踏面 ≒ 600〜650mm が昇降しやすい目安。[慣行]
- 910 モジュールの直階段(13 段、蹴上げ約 200): 上階との関係で階高 2,600〜2,700 の場合、蹴上げ = 階高/段数。階段室の幅は 910 グリッドに合わせる。

## Gaps

- 壁厚の公式な標準値は無く、**一次資料で確認できなかった**(慣行値)。
- 建具(室内ドア・玄関ドア)の標準サイズ表はメーカー依存で、公開一次資料を取得していない。
- サッシ呼称: 日本サッシ協会規格の本文未取得。メーカー(YKKAP・LIXIL・三協)別の細かい差(幅端数・高さ補正)は未収録。
